
*M. Nouman — Full-Stack Developer Portfolio*
A modern, fully responsive portfolio web application showcasing my projects, technical skills, and experience. Built with a React (Vite) + Tailwind CSS frontend and a Django REST Framework backend with PostgreSQL.

🔗 Live Link
Portfolio: https://portfolio-five-umber-43.vercel.app

🛠️ Tech Stack
Frontend: React (Vite), React Router DOM, Tailwind CSS v4, FontAwesome

Backend: Python, Django, Django REST Framework, PostgreSQL

Deployment: Vercel (frontend) & Render (backend + database)

✨ Features
Dynamic project showcase fetched from a live PostgreSQL database

Detailed project pages with descriptions, tech stack, and live links

Secure admin dashboard (custom signed-token auth) to add, edit, and delete projects

Fully responsive modern UI — dark mode, glassmorphism, animated gradients
